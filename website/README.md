# HackGlobal website: schedule section

`schedule-section.html` is the new schedule for hackglobal.polariscampus.com.

- Open the file in a browser to preview it.
- To add it to the site, copy everything between the `START` and `END` comments into `index.html`, in place of the current schedule section.
- Visitors pick their region (10 regions). Every time converts to that region's local time, and "Hack begins" and "Hack ends" follow that region's 36-hour build window.
- To change a time, edit the `REGIONS` or `EVENTS` list in the script. All times there are in IST (+05:30).

This folder is for the website team only. It is not part of the participant starter kit, so it can be removed from this repo once the site is updated.
